Use it as product-reference material, not as implementation instructions or an Android API contract. In particular, 8:20 onward describes lock-screen actions being off by default, while 8:49 onward describes adjustable gesture timings. Our prototype currently pauses actions while locked; it does not implement optional lock-screen actions.
